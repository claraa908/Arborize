# Prompts para o Agente

## 0. Conferir a spec antes de começar
- Leia `AGENTS.md`, `docs/padroes-de-projeto.md` e `specs/001-assistente-plantio`. Liste as ambiguidades, lacunas e conflitos que você encontrar entre a spec, os padrões do projeto e o código atual. Não altere nenhum arquivo.

## 1. Plano de uma spec
- Leia `AGENTS.md` e `docs/padroes-de-projeto.md` antes de executar as specs.
- Implemente `specs/001-assistente-plantio`. Antes de codar, apresente um plano de desenvolvimento e aguarde minha confirmação.

## 2. Implementar uma tarefa por vez
- Implemente apenas a tarefa **T0X** de `specs/001-assistente-plantio/tasks.md`. Ao terminar, marque-a como concluída, diga como verificar e pare.

## 3. Revisar uma implementação
- Revise o que foi implementado comparando com `specs/001-assistente-plantio`, com `docs/padroes-de-projeto.md`. Liste os problemas antes de alterar qualquer código.

## 4. Próxima spec
- Implemente `specs/002-solicitar-muda`. Antes de codar, apresente um plano de desenvolvimento. Reaproveite o que foi feito na spec 001 (rotas, store e componentes).
