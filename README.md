# 🌳 Sistema de Gestão e Monitoramento de Arborização Urbana

> Sistema para mapeamento, acompanhamento e gestão de áreas de plantio urbano, desenvolvido como projeto prático acadêmico em parceria com a **AMMA (Autarquia Municipal do Meio Ambiente)**.

## 🪴 Sobre o projeto
O sistema tem o propósito de auxiliar a AMMA na divulgação de seus projetos e eventos, além de conscientizar a população sobre o trabalho realizado em relação à arborização do município de Quixadá. Ao mesmo tempo, o sistema também atua como uma ferramenta de gestão interna que fornece recursos para organização de documentos de licitação, gerenciamento de denúncias e monitoramento de áreas árborizadas.
